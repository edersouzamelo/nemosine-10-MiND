# Changelog

## 1.0.5, 2026-09-03

- Added a native Windows MSI with local controller and visual interface.
- Added an agnostic Plug and Play tutorial for Python and HTTP integrations.
- Added UI configuration for mock, OpenAI and Anthropic providers.
- Protected Windows provider keys with Windows Credential Manager.
- Added filtered JSON export, full local backup, storage occupancy and protected
  deletion.
- Replaced the placeholder installer license with the Apache License 2.0 legal
  pack and dependency notices.
- Expanded CI and Windows installation validation.

## 1.0.4, 2026-09-02

- Added the refreshed control-center interface and MiND cube identity.
- Added navigation for provider selection, integration, updates and local data
  operations.

## 1.0.3, 2026-08-23

- Added the first local visual interface, public Python API and `mind` CLI.
- Added Cycle Artifact v1, JSONL and SQLite storage, history and migration.
- Added provider-neutral adapters for the offline mock, OpenAI and Anthropic.

## 1.0.2

- Last release from the original minimal reference implementation.
